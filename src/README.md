# Reproducible code

See [the command guide](../docs/commands.md) for current entry points and prerequisites.

Student-facing: `descriptive_analysis.py`, `moving_average_analysis.py`,
`moving_average_all_genres.py`. Final dataset: `final_dataset.py build|validate`.

Other modules preserve ingestion, metadata, acquisition, classifier and genre history.
They remain here to preserve imports and frozen production implementations. Their
presence is not a request to rerun acquisition/inference. Archived pilot guides and
reports are linked from [archive/README.md](../archive/README.md).
