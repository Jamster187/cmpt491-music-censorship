# Historical research — preserved, not current entry points

- [experiments/](experiments/): completed Phase 2A, 2B and 2A-R reproduction guides.
- [intermediate_reports/](intermediate_reports/): checkpoint narratives, metadata/source feasibility studies, acquisition reviews, classifier-panel and genre-refinement artifacts.
- [old_methodology/](old_methodology/): superseded population/panel/refinement narratives.

Dates, counts, recommendations and incomplete statuses describe their historical stage;
start with [current analysis](../analysis/README.md) and [final datasets](../data/public/README.md).
Machine-readable receipts retain original paths and hashes as provenance, not current
output destinations. The [relocation manifest](../docs/repository_cleanup_manifest.json)
maps moved files. Historical paths in frozen receipts and the preserved former root
README are intentional; current navigation and executable references are updated.

Private `data/experiments/` is different from the former tracked `experiments/` guides.
It contains model environments, pinned checkpoints, cached pilot results and production
state. Those local-only assets remain ignored and unmoved because production depends
on them. Likewise, `data/processed/`, `data/lyrics/` and `data/cache/` are untouched.
