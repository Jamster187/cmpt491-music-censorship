# Genre pilot artifacts

These are experimental outputs for 300 songs, not production genre assignments.
`sample.csv` freezes 63 named challenge cases and 237 songs selected by a seeded
hash within period/rank/artist-credit strata. `pilot.csv` holds the reproducible
candidate decisions; `summary.json` counts outcomes and existing evidence.
An empty primary genre means abstention, not Other. Evidence and revisions remain
in the ignored local `data/experiments/genre_pilot/` directory.
