# LLM genre pilot artifacts

Same frozen 300 songs; these files are experimental and do not update the public
master dataset. `metadata.json` contains baseline A predictions; `identity.json`
contains 77 baseline B predictions; `repeat.json` contains 42 rebatched repeats;
`exact_repeat.json` contains 30 byte-identical request repeats. Predictions are
unaltered model responses, exported after validation. `inputs.json` is the exact
metadata evidence supplied to A; B omits its genre_evidence key. `manifest.json`
records frozen settings and hashes. `runs.json` records request/response hashes,
dates, timings and reported token usage. Raw transport logs remain local.

`review.csv` is a separately authored assistant qualitative assessment, not model
self-scoring or independent human ground truth. `review_template.csv` is blank
and suitable for a team member's independent review. Review evidence never enters
classifier inputs. `summary.json` and the main report are regenerated by code.
